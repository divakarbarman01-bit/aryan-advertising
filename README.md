# Aryan Advertising

Premium frontend website for **Aryan Advertising** — a professional signage & advertising company based in Goa, India.

## Tech Stack

- React.js + Vite
- Tailwind CSS v4
- Framer Motion
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
  animations/     # Framer Motion variants
  assets/         # Static assets
  components/     # UI, layout, sections
  constants/      # Site content & data
  hooks/          # Custom React hooks
  pages/          # Page compositions
  App.jsx
  main.jsx
  index.css
```

## Features

- Sticky navbar with scroll state
- Animated hero, counters, and section reveals
- Services, portfolio lightbox, testimonials slider
- Contact details + Google Maps embed
- Floating WhatsApp / Call / Back-to-top
- Scroll progress bar & loading screen
- Fully responsive & SEO-friendly markup
